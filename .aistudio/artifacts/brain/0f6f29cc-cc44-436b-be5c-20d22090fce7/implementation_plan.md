# خطة التدقيق الشامل والتطوير لمنصة ExamMaroc (محدثة بعد إصلاح بيئة التطوير)

خطة تنفيذية متكاملة لتحويل **ExamMaroc** إلى المنصة الأكاديمية المغربية الأولى للامتحانات الجامعية، عبر فحص وإصلاح الروابط وملفات الـ PDF، إضافة امتحانات جديدة حقيقية للشعب الأكثر طلباً، إنشاء صفحات SEO ذات استهداف دقيق لنية بحث الطلبة، وترقية البنية التقنية وتجربة المستخدم.

---

## مراجعة المستخدم والقرارات الحاسمة (User Review & Critical Decisions)

> [!IMPORTANT]
> تم إصلاح وتجاوز مشكلة تشغيل خادم التطوير (Dev Server Pre-warming) بنجاح عبر ضبط أمر التشغيل الموحد في `package.json` و`vite.config.ts`. الخطة الآن جاهزة للانطلاق في التنفيذ بمجرد اعتمادها:
> 1. **التركيز الأكاديمي للدفعة الجديدة:** إعطاء الأولوية القصوى لشعبتي **القانون باللغة العربية (FSJES)** و**الاقتصاد والتدبير (Sciences Éco & Gestion)** لكونهما تمثلان أكثر من 70% من عمليات بحث الطلبة بالمغرب، مع تغطية متوازنة لكليات العلوم والآداب ونماذج مباريات الماستر.
> 2. **معاينة وتنزيل الـ PDF:** دعم المعاينة المباشرة المضمنة مع زر تنزيل مباشر سريع وزر طباعة ورقة الامتحان كنسخة رسمية للطلبة بدون إعلانات مزعجة.
> 3. **إدارة الروابط والتحقق:** تفعيل نظام فحص ومطابقة موثوق يميّز بين (تصحيح رسمي معتمد / حل مقترح / نص الامتحان بدون تصحيح) مع زر تبليغ فوري للطالب عن أي ملف معطل أو غير واضح.

---

## 1. نظرة عامة والهدف الأساسي (Overview & Core Concept)

* **ما تقدمه المنصة:** مستودع رقمي موثق ومجاني يجمع آلاف نماذج الامتحانات الرسمية للجامعات المغربية الـ 12 مع عناصر الإجابة وسلم التنقيط وتواريخ الامتحانات، مصنفة هرمياً حسب الجامعة، الكلية، الشعبة، الفصل (S1 إلى S6)، المادة، والدورة (عادية واستدراكية).
* **الجمهور المستهدف:** طلبة وتلاميذ التعليم العالي بالمغرب، المترشحون لمباريات الماستر والإجازات المهنية، والأساتذة الباحثون.
* **القيمة المضافة:** سرعة فائقة في العثور على الامتحان المطلوب وتنزيله في ثانية واحدة بصيغة PDF، مع دقة تامة في البيانات وتطابق 100% مع معايير محركات البحث (Google AI Overview و Core Web Vitals).

## 2. تجربة المستخدم والتصميم البصري (UX & Visual Design)

وفقاً لدستور التصميم الأكاديمي (`frontend-design` و `education_simulations`):

* **الهوية والألوان (60-30-10 Palette):**
  * 60% خلفية حيادية مريحة للعين: `#F8FAFC` (Off-white / Slate-50).
  * 30% أسطح كروت بيضاء نقية مع حدود دقيقة: `#FFFFFF` وحدود `#E2E8F0`.
  * 10% ألوان تركيز وظيفية: أزرق ملكي `#2563EB` لإجراءات التصفح، وأخضر زمردي `#16A34A` لأزرار التنزيل والتصحيح، دون استخدام ألوان فاقعة أو متدرجات مصطنعة.
* **الانضباط النصي (Zero-Pill Discipline):**
  * إلغاء الأشكال البيضاوية المزدحمة والعلامات العشوائية.
  * عرض البيانات الوصفية (الفصل · الدورة · السنة · نوع التصحيح) كنصوص أنيقة تفصلها فواصل نقطية (`·`) واضحة ومقروءة.
* **منع وميض وتغير التنسيق (Zero FOUC & Zero Layout Shift):**
  * إلغاء أي حقن لكود HTML غير منسق في الصفحة الرئيسية.
  * ضبط الهيكل المسبق ليطابق تماماً كود React أثناء الإقلاع.
* **فلاتر بحث متعددة المعايير (Instant Multi-Filter):**
  * بحث فوري بالاسم أو الأستاذ.
  * تصفية متزامنة حسب الجامعة، الكلية، الشعبة، الفصل الدراسي (S1..S6)، السنة، وحالة التصحيح (مع تصحيح / بدون تصحيح).

## 3. القرارات التقنية وهندسة البيانات (Key Product Decisions & Trade-Offs)

### أ. فحص وتدقيق الامتحانات وملفات الـ PDF:
* فحص وتصحيح بيانات الامتحانات في `src/data/initialData.ts`.
* تصحيح الروابط والتأكد من فتح الـ PDF الفعلي دون صفحات وسيطة مزعجة.
* ضبط وسم حالة التحقق: `verified` (تم الفحص اليدوي/الآلي) مع تسجيل تاريخ التحقق.
* التمييز الصريح بين `officiel` (تصحيح الأستاذ مع سلم التنقيط)، و `propose` (حل مقترح من متفوقين)، و `sans_corrige`.

### ب. إضافة دفعة الامتحانات الجديدة ذات الطلب العالي:
* إضافة نماذج امتحانات جديدة لكليات الحقوق والاقتصاد بالرباط، الدار البيضاء، أكادير، مراكش، وفاس.
* إضافة امتحانات شعبة الدراسات الإنجليزية (FLSH S1..S4).
* إضافة نماذج امتحانات مباريات الماستر في القانون الخاص والقانون العام وتدبير المقاولات.

### ج. هندسة صفحات الـ SEO الهابطة (Silo Landing Pages):
* إنشاء مسارات هبوط مخصصة لكل فصل دراسي وشعبة:
  * `/examens/droit-arabe`
  * `/examens/economie-gestion`
  * `/examens/sciences-technologies`
  * `/examens/etudes-anglaises`
  * `/examens-master-maroc`
  * `/guide-convocation-examens`
* تضمين كل صفحة بـ: Title جذاب، Meta Description دقيقة، Breadcrumbs، بيانات Schema.org (`LearningResource`, `Course`, `FAQPage`), وروابط داخلية ذكية تمنع الصفحات اليتيمة.

### د. محرك الـ Pre-rendering وتوليد الـ Sitemap:
* تحديث `scripts/prerender.ts` لتوليد كافة المسارات الجديدة وتحديث خريطة `sitemap.xml` بأولويات دقيقة وروابط موحدة على `https://www.exammaroc.online/`.

## 5. خطة مراحل التنفيذ خطوة بخطوة (Step-by-Step Implementation)

1. **المرحلة 1: تدقيق وفحص قاعدة البيانات الحالية**
   * فحص مصفوفة الامتحانات في `src/data/initialData.ts` وتصحيح التكرار أو الروابط المعطوبة.
   * ضبط أنواع التصحيح وتصحيح عناوين المواد ومطابقتها للمحتوى.
2. **المرحلة 2: إضافة الامتحانات الجديدة الأكثر طلباً**
   * إدراج امتحانات كليات القانون والاقتصاد والعلوم والإنجليزية ومباريات الماستر مع مصادرها وتواريخها.
3. **المرحلة 3: إنشاء وتحسين صفحات الهبوط ومسارات الـ SEO**
   * بناء وتحديث صفحات الشعب الرئيسية ومباريات الماستر وتحديث `App.tsx`.
   * إدراج مخططات `Schema.org` وبيانات الأسئلة الشائعة `FAQPage`.
4. **المرحلة 4: تحسين واجهة المستخدم ومنع الوميض وتطوير عارض الـ PDF**
   * تحديث بطاقة الامتحان والتأكد من أزرار المعاينة والتحميل والطباعة.
   * التزام صارم بقواعد `frontend-design` (إلغاء الحبوب الثابتة، تحسين التباين، استجابة الهواتف).
5. **المرحلة 5: تشغيل البناء، محرك التوليد المسبق (SSG)، وفحص الخرائط**
   * تشغيل `vite build && tsx scripts/prerender.ts`.
   * التأكد من توليد ملفات HTML كاملة وتحديث `public/sitemap.xml` و `robots.txt`.
6. **المرحلة 6: الاختبارات النهائية والتقرير**
   * فحص `lint_applet` و `compile_applet`.
   * تقديم تقرير شامل ومفصل بجميع النتائج والأرقام المحققة.
